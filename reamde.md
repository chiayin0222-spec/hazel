## 🌟 Key Features

- **Personalized Header**: Stylish greeting card stating "Hello, my name is Hazel".
- **Dynamic Clock & Date**: Live digital clock updating in real-time alongside a beautifully formatted calendar date.
- **Modern Glassmorphic UI**: Frosted glass card visual effects using CSS `backdrop-filter` and soft, elegant glowing highlights.
- **Interactive Parallax Tilt**: The main card tilts smoothly in response to mouse movements, creating a premium 3D depth effect.
- **Custom Ambient Aurora**: Slow-moving glowing background aurora blobs, with a "Shift Aurora Color" button to alternate between 4 curated color palettes.

## 🛠️ How to Run Locally

Since this project is built entirely with vanilla client-side HTML, CSS, and JS, no local server installation is required:
1. Clone this repository.
2. Open [index.html](file:///d:/Hazel/index.html) directly in any modern web browser.
